# Glossary

| Term | Meaning |
|------|---------|
| **Agent** | System that uses an LLM to decide actions over multiple steps toward a goal |
| **Single-agent** | One decision-making agent owns the task (may use many tools and loops) |
| **Multi-agent** | Two or more agents with distinct roles collaborate via orchestration, routing, or handoff |
| **Tool / Function** | External capability the model can invoke (API, DB, code runner) |
| **ReAct** | Reason → Act → Observe loop |
| **Orchestrator** | Agent that plans and delegates to workers |
| **RAG** | Retrieve documents then generate grounded answers |
| **HITL** | Human-in-the-loop — approval or correction checkpoints |
| **Guardrail** | Automated policy check on inputs, outputs, or tool calls |
| **Handoff** | Transfer control and context between agents |
| **Map–Reduce** | Parallel chunk processing with merged aggregate result |

For pattern details see [README.md](README.md).
