# শব্দকোষ

| শব্দ | অর্থ |
|------|------|
| **Agent (এজেন্ট)** | LLM দিয়ে লক্ষ্যের দিকে একাধিক ধাপে সিদ্ধান্ত নেওয়া সিস্টেম |
| **Single-agent** | এক সিদ্ধান্ত-গ্রহণকারী এজেন্ট পুরো কাজের দায়িত্বে (অনেক টুল/লুপ থাকতে পারে) |
| **Multi-agent** | দুই বা ততোধিক ভিন্ন ভূমিকার এজেন্ট orchestration/routing/handoff-এ সহযোগিতা |
| **Tool / Function** | মডেল invoke করতে পারে এমন বাহ্যিক ক্ষমতা (API, DB, কোড রানার) |
| **ReAct** | Reason → Act → Observe লুপ |
| **Orchestrator** | পরিকল্পনা ও ওয়ার্কারদের কাজ বরাদ্দকারী এজেন্ট |
| **RAG** | ডকুমেন্ট রিট্রিভ করে grounded উত্তর তৈরি |
| **HITL** | Human-in-the-loop — অনুমোদন বা সংশোধন চেকপয়েন্ট |
| **Guardrail** | ইনপুট, আউটপুট, বা টুল কলে স্বয়ংক্রিয় নীতি যাচাই |
| **Handoff** | এজেন্টের মধ্যে নিয়ন্ত্রণ ও প্রসঙ্গ হস্তান্তর |
| **Map–Reduce** | সমান্তরাল chunk প্রক্রিয়া, তারপর merge |

বিস্তারিত: [README.md](README.md)।
