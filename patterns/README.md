# Pattern Examples

Each numbered folder is one **agentic AI design pattern** with:

| File / folder | Purpose |
|---------------|---------|
| `README.md` | Pattern definition, when to use it, related patterns |
| `use-case.md` | Real-life scenario — **you fill this in** |
| `example/` | Runnable code, prompts, and config |
