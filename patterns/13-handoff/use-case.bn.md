# Use Case: Handoff — Corp IT Helpdesk

শেয়ার্ড সিনারিও: [Corp IT Helpdesk](../../docs/bn/use-cases/it-helpdesk.md) — VPN, password reset, Outlook issues।

## কেন Handoff মানায়

Tier-1 FAQ exhausted — Tier-2 VPN specialist-এ context সহ transfer।

## উদাহরণ ফ্লো

1. Tier-1 initial triage।
2. Determines escalation needed।
3. Handoff state to Tier-2 agent।
4. Tier-2 collects VPN logs, deep steps।
5. Unified thread, new specialist owner।

## এই সিনারিওতে নয়

Single generalist, no escalation path।
