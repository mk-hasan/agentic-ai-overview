# Use Case: Routing — Corp IT Helpdesk

শেয়ার্ড সিনারিও: [Corp IT Helpdesk](../../docs/bn/use-cases/it-helpdesk.md) — VPN, password reset, Outlook issues।

## কেন Routing মানায়

এক chat entry — VPN, password, email intents; প্রতিটির আলাদা handler ও tool set।

## উদাহরণ ফ্লো

1. User mixed intent message।
2. Router classifies primary intent।
3. VPN handler OR identity OR email path।
4. Specialist tools + prompt।
5. Single coherent reply।

## এই সিনারিওতে নয়

Monolithic one-size-fits-all agent।
